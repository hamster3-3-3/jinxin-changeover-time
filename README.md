# 晉欣各線別平均換線時間追蹤平台

點擊任一線別圖卡，可在趨勢圖下方展開目前年／月／週／日範圍內的逐日計算明細，包含每日平均換線時間與當日換線最久品項；沒有換線記錄的日期也會列為 0.0 分。頁面底部可依目前範圍直接下載 PDF 報告，比較名稱會自動切換為當年／前年、當月／前月、當週／前週或當日／前日，內容包含換線時間改善／增加／持平線別數量及品項變化原因分析。

## 計算口徑

- 線別：四度一線～四度四線、綜合一線～綜合三線。同一主線別下的設備或字尾變體會合併計算。
- 合格換線：換線時間大於 0 且不超過 20 分鐘，且同列未填寫休息時間。
- 期間平均：先計算每日合格換線記錄的單純平均，再依期間日數取平均。週別固定以 7 天計算；月別以當月 28、29、30 或 31 天計算；無合格換線的日期視為 0。
- 改善判定：所選範圍的平均低於前一個對應期間時視為改善。

## 資料讀取方式

網站開啟後會直接讀取：

`https://hamster3-3-3.github.io/jinxin-dashboard/data/manifest.json`

再依 manifest 清單載入原始生產日報。會先載入最近 3 個月供使用者立即查看，再於背景補齊歷史月份。可依年別、月別、週別或日別切換。當原網站的 manifest 新增日報後，本網站重新開啟即會同步。

網頁也保留「匯入更新」，可在瀏覽器中臨時加入尚未上傳的新日報，不會改寫原始檔案。
